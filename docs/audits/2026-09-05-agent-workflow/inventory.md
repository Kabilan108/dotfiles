## Invocation consistency

Codex already has `allow_implicit_invocation: false` for `bro`, `code-walkthrough`, and `terminal-control`. Claude has `disable-model-invocation: true` for `bro`, but not the latter two. The `hidden: true` field in `agent-browser` should not be treated as proof that either harness removes its description; it is visible in this Codex session catalog.

Map one intended policy to each harness's supported metadata and verify discovery in fresh sessions. Claude's manual-only flag and Codex's implicit-invocation flag are different controls; do not promise identical context savings. [Claude skills documentation](https://code.claude.com/docs/en/skills), [OpenAI skill metadata](https://learn.chatgpt.com/docs/build-skills).

“Human-selected” means the user intentionally invokes that workflow. An approved orchestration workflow can read shared reference files for its substeps; those need not become separately discoverable manual-only skills.
