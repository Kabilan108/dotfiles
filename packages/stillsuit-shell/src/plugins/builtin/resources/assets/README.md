# Host icons

SVGs from [Lucide](https://lucide.dev/), revision `d672fc43dbf60962d9d829e35bc3b3e5ed89a178`.

- `server.svg`: [upstream source](https://raw.githubusercontent.com/lucide-icons/lucide/d672fc43dbf60962d9d829e35bc3b3e5ed89a178/icons/server.svg), used for sietch.
- `laptop.svg`: [upstream source](https://raw.githubusercontent.com/lucide-icons/lucide/d672fc43dbf60962d9d829e35bc3b3e5ed89a178/icons/laptop.svg), used for jacurutu.

The SVG geometry is unchanged. `HostIcon.qml` replaces `currentColor` with the
current theme color before Qt decodes the image. See `LICENSE.lucide` for the
upstream ISC and MIT license notices.
