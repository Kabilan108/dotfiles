# Report and log recipe

## Reports

Lead with status and the conclusion. Include timestamped sources, key metrics with context, findings grouped by impact, supporting tables or charts, carryover/blockers, and recommended next actions. Distinguish data collection completeness from publication success.

For incidents include severity, owner, duration, impact, timeline, root cause, contributing factors, corrective actions, and verification.

## Implementation logs

Keep the top of the page current:

- overall state and active milestone;
- last update and next action;
- completed work with commits/files;
- tests and runtime verification;
- blockers or required decisions;
- deviations from the original plan and why;
- remaining work.

Prefer checkpoint updates over a transcript. Preserve decisions and deviations, but collapse routine command output.
