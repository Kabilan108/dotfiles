# Artifact checks

Verify changed content and links. Render new or materially changed layouts where readability needs inspection; test the controls you changed. Choose viewport checks for the likely reader rather than a fixed matrix.

For stateful controls, exercise storage-denied and clipboard-unavailable paths. Keep the result usable in memory and provide selectable text or a download when copy is unavailable. Verify the published identity and content through PageBin when publishing. A text-only update to a previously checked layout does not require repeating every visual check.
