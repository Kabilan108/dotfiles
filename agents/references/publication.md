# PageBin publication preference

Tony authorizes publishing and updating task-relevant HTML artifacts through PageBin as part of requested HTML communication. An explicit local-only or draft-only instruction takes precedence. Reuse the existing identity on updates; publish a second copy only when intended. This preference does not authorize sending messages, publishing unrelated material, changing access controls, or deleting artifacts.

Use the configured protected PageBin service and its current CLI contract. Exclude credentials and secrets, respect source-specific sharing restrictions, and keep local receipts out of commits. Verify the resulting artifact and return its viewer link. Existing authorization carries through follow-ups; do not ask again for the same covered operation.
